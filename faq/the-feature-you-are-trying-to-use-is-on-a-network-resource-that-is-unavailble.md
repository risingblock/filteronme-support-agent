This mostly shows up on the older FilterOnMe Windows installer (1.0.x/early 2.x) — it's rare on current versions. It happens after an incomplete uninstall (for example, deleting the app folder instead of using the uninstaller), followed by a reinstall or update attempt. You might also see: "The older version of FilterOnMeWindows cannot be removed. Contact your technical support group."

![screenshot](images/95-the-feature-you-are-trying-to-use-is-on-a-network-resource-that-is-unavailble/1.png)

This is a Windows problem, not a FilterOnMe one. We've had customers fix it by following the steps in this guide: [thegeekpage.com fix guide](https://thegeekpage.com/the-feature-you-are-trying-to-use-in-on-a-network-resource-that-is-unavailable-in-windows-10-fix/)
