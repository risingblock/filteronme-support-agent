Seeing this on Windows?

> Another installation is in progress. You must complete that installation before continuing this one.

Fix it:

1. Restart your computer.
2. Wait a minute after logging back in.
3. Open Task Manager, find `msiexec.exe`, and end the process.
4. Run the installer again.
